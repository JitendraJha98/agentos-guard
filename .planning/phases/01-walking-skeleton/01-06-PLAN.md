|----------|-------------|
| LangGraph agent → SDK PEP | The agent's tool call (possibly driven by attacker-controlled fetched content) crosses into the governed boundary; the PEP must intercept BEFORE execution. |
| deny decision → tool execution | A deny must structurally prevent the tool (egress) from running — not merely log a warning. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
