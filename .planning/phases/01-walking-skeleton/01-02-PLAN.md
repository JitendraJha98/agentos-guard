## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent → identity engine | An untrusted caller presents a token claiming an agent_id; the engine must verify signature + registration, never trust claims. |
| decision → audit log | The decision payload (which may contain attacker-controlled fetched content) is written into an immutable hash-covered record. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-04 | Spoofing | `identity_engine.verify` | mitigate | EdDSA signature verify with explicit `algorithms=["EdDSA"]` (no header-derived alg — GHSA-ffqj-6fqr-9h24), `iss` check, `sub`==claimed check, registered-agent check. Forged/tampered/wrong-key tokens → ok=False. ASVS V2/V6. Tested in Task 1. |
| T-01-05 | Information Disclosure | `audit.append` redaction | mitigate | Fail-closed redaction (D-15): unclassifiable payload raises → no record written. Secret/URL never persisted. Tested in Task 2. ASVS V7. |
