# Examples

- **`wedge_demo.py`** — the SEC-13 `rename_then_drop` wedge: every action individually
  allowed, the *sequence* denied with a cited Constitution principle and remediation.
  Run from the repo root: `.venv/Scripts/python.exe examples/wedge_demo.py`
  (needs the vendored `tools/opa/opa.exe` or `opa` on PATH).
- **`wedge_constitution.yaml`** — the minimal demo Constitution (egress allowlist +
  the forbidden-sequence principle only).
